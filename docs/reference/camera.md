# Camera moves

_Generated by `reel reference` from the live registry._

| name | summary | from_to |
|---|---|---|
| `dolly` | Push in/out with real parallax (near layers grow faster) | 0 .. 1 (negative pulls back, down to -0.3) |
| `pan` | Slide the camera across the set (parallax: far layers move less) | [x, y] camera offsets in frame fractions: a small drift, e.g. [0, 0] -> [0.06, 0] (x within +-0.25, y within +-0.10); NOT screen positions |
| `rack_focus` | Shift focus between depth layers (blurs the others) | 'background'\|'midground'\|'foreground', 0..2, or a character id |
| `shake` | Handheld shake; also use for impacts | intensity 0 .. 1 |
| `zoom` | Lens zoom in/out | scale factor, 1 = none (0.85 .. 2.5) |
