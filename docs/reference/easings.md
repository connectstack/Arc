# Easings

_Generated by `reel reference`._

| name | behaviour |
|---|---|
| `anticipate` | pulls back first, then accelerates (back-in) |
| `anticipate_overshoot` | wind-up before and overshoot after (back in-out) |
| `bounce` | lands and bounces to rest (bounce-out) |
| `bounce_in` | bounces away from the start value |
| `ease_in` | start slow, accelerate (quadratic) |
| `ease_in_cubic` | slow start, strong acceleration |
| `ease_in_out` | smooth start and stop (cubic) - the default |
| `ease_in_out_quint` | very pronounced slow-fast-slow |
| `ease_out` | start fast, decelerate (quadratic) |
| `ease_out_cubic` | fast start, long soft landing |
| `elastic` | rubber-band wobble around the target (elastic-out) |
| `expo_out` | very fast start with a long tail (whip-pans, slams) |
| `hold` | step: hold the old value, jump at the end (comedy hold frames) |
| `linear` | constant speed |
| `overshoot` | passes the target then settles back (back-out) |
| `sine_in_out` | gentle sinusoidal in/out |
| `spring` | damped spring settling on the target |
